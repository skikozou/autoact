全て **1080×2392 縦画面 / Gboard 日本語 12キー + QWERTY 追加** 前提。他解像度は probe 再実行が必要。

## hira 12キー (`keymap.json`)

### レイアウト

```
       col:219-433   433-647   647-861
row1:  [あ 326,1645] [か 540,1645] [さ 754,1645]   [削除 968,1645]
row2:  [た 326,1822] [な 540,1822] [は 754,1822]   [右   968,1822]
```

### 濁点キー (dak) — フリック 3 方向で 1 発変換

`dak_xy=(326, 2177)` を直前入力後にフリックする:

| フリック方向 | 効果 | 例 |
|---|---|---|
| ← (L) | 濁点 | は→ば, か→が, う→ゔ, つ→づ |
| → (R) | 半濁点 | は→ぱ, ひ→ぴ, ふ→ぷ, へ→ぺ, ほ→ぽ |
| ↑ (U) | 小文字化 | あ→ぁ, や→ゃ, つ→っ, う→ぅ, わ→ゎ |
| ↓ (D) | (未使用) | — |
| C (tap) | — | 旧実装は N 回タップで循環していたが現在は未使用 |

→ `flick.py` の `CHAR_MAP` に **(base_key, direction, dak_dir)** の三つ組で全文字ぶん展開済み。
`dak_dir` は `None`/`"L"`/`"R"`/`"U"` のいずれか。

**旧実装からの変更点**: 以前は「濁点キーを N 回タップして候補を循環」させていた (`dak_count` int)。現行 Gboard 12キーは濁点キーもフリックで一発変換できるため、`ぱ` (旧: dak×2 タップ) や `ゔ` (旧: dak×2) 等の 2 段変換もフリック 1 発で入るようになり、multi-tap 誤爆リスクが消えた。

## alpha QWERTY (`alpha_qwerty.json`)

10-10-9-7-2 のスタガード配列 + shift/del/space/enter。

### 座標 (y=1596/1744/1892/2040/2188)

| 行 | y | キー | x 順 |
|---|---|---|---|
| 1 | 1596 | 1234567890 | 54, 162, 270, 378, 486, 594, 702, 810, 918, 1026 |
| 2 | 1744 | qwertyuiop | 同上 |
| 3 | 1892 | asdfghjkl  | 108, 216, 324, 432, 540, 648, 756, 864, 972 |
| 4 | 2040 | zxcvbnm    | 216, 324, 432, 540, 648, 756, 864 |
| 5 | 2188 | , .        | 325, 595 (canvas) |

補助:
- shift: (85, 2040)
- del:   (994, 2040)
- space: a11y click `key_pos_space` (canvas キーとしては (540, 2188))
- enter: a11y click `key_pos_ime_action`

### symbol B (数字パッド)

物理的にはあるが座標は保持していない。B 検出時は canvas 座標 (325, 2170) をタップして A に切替 (`SYMBOL_TOGGLE_A_B_XY`)。

## a11y キー ID (Gboard, IME_PKG = `com.google.android.inputmethod.latin`)

| 用途 | ID | 露出モード |
|---|---|---|
| 空白 | `key_pos_space` | 全モード |
| Enter | `key_pos_ime_action` | 全モード |
| 削除 | `key_pos_del` | 全モード |
| モード: hira↔alpha | `key_pos_switch_hiragana_alphabet` | hira のみ |
| モード: → symbol | `key_pos_switch_to_symbol` | hira/alpha |
| モード: → prime 復帰 | `key_pos_back_to_prime` | symbol のみ |
| shift (symbol) | `key_pos_shift` | alpha/symbol |
| 右カーソル (確定+移動) | `key_pos_right_arrow` | hira のみ |
| 左カーソル | `key_pos_left_arrow` | hira のみ |
| Undo | `key_pos_undo` | hira のみ |
| ja 12キー本体 | `key_pos_ja_12keys_1..12` | hira のみ |
